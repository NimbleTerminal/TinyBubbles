Bubble Tea for tiny screens

TinyGo compiles Go for microcontrollers. Bubble Tea is a Go framework for interactive terminal apps. TinyBubbles brings Bubble Tea to small embedded displays, so you can try a Go interface in your browser and run the same UI on hardware.
