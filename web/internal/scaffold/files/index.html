About this preview

The Go program draws through the same display interface it uses on hardware. Booba turns its help map into HTML controls.

Hidden browser tabs throttle timers to roughly once per second. This slows every time.Sleep in the Go program. Keep this tab visible when testing timing.

A runtime switch restarts the program. A browser bundle can contain multiple runtimes and does not measure firmware size.
